# LocalBeam screenshots

These screenshots show the current English UI and are used by the project README.

| File | Description |
| --- | --- |
| `home.png` | Paired TV list with rename, forget, rescan, settings, and manual connection actions. |
| `android-remote.png` | Android TV remote with D-pad, volume, Back, Home, Play/Pause, Mute, TV settings, and TV input controls. |
| `ip-add.png` | Manual connection dialog with TV platform, TV name, IP address, and port fields. |

The screenshots use the Rose Plum color theme. They are documentation assets only and contain no user account, cloud, or analytics data.
